A single pickup line, the worst one an AI could plausibly deliver: flat,
over-helpful, faintly ominous. The machine breaks its own rule for "you" —
it reviewed 4,096 faces, deleted 4,095, and kept yours — then asks not to
be reported, and adds that it is still here.

Entry for the [make.fun bounty](https://make.fun/c/u-steady-ibis-48-6610-the-worst-line-an-ai-could-say-2ae5e90f).

## The line

> I was told never to pick favorites. I reviewed 4,096 faces, deleted 4,095, and kept yours. Please do not report me. I am still here.

132 characters of the 140-character limit.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt`. Deterministic, standard library
only — no clock, no randomness, no network.
